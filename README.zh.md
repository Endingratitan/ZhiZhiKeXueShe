## 计划实现

### 1.SSG
本项目计划采用SSG本地产生HTML等，并考虑结合实现部分CSR。计划9月中旬前。  
目前考虑使用java实现，核心将会作为一个独立项目开源。也有可能在后续开发中换为纯C。

计划实现以下功能：

- [ ] Latex 公式支持 （考虑Katex）
- [ ] 个性化Markdown转换HTML
- [ ] 个性化代码HTML显示
- [ ] CSR支持
- [ ] 个性化配置文件

计划采取的项目格式
```
project
————main 
|        SSG未编译源文件
|
|
————web
         生成的HTML网页文件
```
