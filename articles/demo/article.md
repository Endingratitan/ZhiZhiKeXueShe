> [!abstract] 摘要
> 从伽利略的等时性观察到小角近似，再到数值验证：本文用一套简易装置测量单摆周期，并讨论摆角对周期的影响。实验表明，当摆角 **θ₀ ≲ 0.1 rad** 时，等时性近似成立；角度继续增大后，非线性修正不可忽略[^.]。

## 研究背景

伽利略在 1583 年注意到比萨教堂吊灯的摆动，提出了单摆的**等时性**假设：摆的周期似乎与振幅无关。这个观察后来成为摆钟与早期精密计时的基础[^1]。

### 小角近似

设摆长为 \(L\)，重力加速度为 \(g\)，当摆角 $\theta_0 \ll 1$ 时，小角近似给出经典周期公式：

\[
T_0 = 2\pi \sqrt{\frac{L}{g}}
\]

若保留非线性项，周期的一阶修正为

$$
T(\theta_0) \approx T_0 \left(1 + \frac{1}{16}\theta_0^2\right)
$$

其中 $\theta_0$ 以弧度计。由此可见，**摆角越大，周期越长**；这也是摆钟需要限制振幅的原因。

```python
import numpy as np

G = 9.79          # 本地重力加速度
L = 0.500         # 摆长 / m

def period_linear(l, g):
    return 2 * np.pi * np.sqrt(l / g)

def period_nonlinear(l, g, theta0):
    t0 = period_linear(l, g)
    return t0 * (1 + theta0 ** 2 / 16)

for th in (0.05, 0.10, 0.20, 0.40):
    print(f"theta0={th:.2f}  T0={period_linear(L, G):.4f}  "
          f"T={period_nonlinear(L, G, th):.4f}")
```

## 讨论

1. 在 $θ_0 \le 0.1\ \mathrm{rad}$ 范围内，周期变化小于仪器分辨率（`0.001 s`），等时性成立。
2. 随着摆角增大，非线性项 $\theta_0^2/16$ 快速上升；这也是~~早期钟表~~ 高精度摆钟必须限制摆角的原因。
3. 若需要更高精度，可直接数值求解完整的运动方程：

> 运动方程：$\ddot{\theta} + \frac{g}{L}\sin\theta = 0$。该方程没有初等闭式解，通常用椭圆积分或数值积分处理。

## 结论

单摆的等时性是小角近似下的结论，而非严格定律。实验与数值结果都支持一阶修正 $T \approx T_0(1+\theta_0^2/16)$；对普通教学实验而言，把摆角控制在 10° 以内即可获得千分之一的精度。
